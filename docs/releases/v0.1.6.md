# Night Voyager v0.1.6

> Release type: `local synthetic portfolio release`

## Summary

Night Voyager `v0.1.6` 将已合并、可复核的本地工作收敛为一个
local synthetic、provider-free 的 portfolio release。当前 migration identity
仍为 `0015`；本版本不改变产品 authority。
The current migration identity is migration `0015`.

- **governed complementary-evidence Slice 0 safe stop：** PR #87 已将
  complementary-evidence Slice 0 固定为永久 local `evaluation_invalid` safe
  stop。本 release 不宣称 information gain、`MkeCaptureArtifactV2`、candidate
  persistence、Slice 1/2 unlock 或 successful cross-project evidence loop。
  The governed stop remains explicit: no information gain, no MkeCaptureArtifactV2,
  no candidate persistence, no Slice 1/2 unlock, and no successful cross-project evidence loop。
- **advisor-centered presentation：** PR #94、PR #95、PR #97 与 PR #98 收敛
  reference-driven advisor workspace、bilingual presentation、accessibility/browser
  coverage 与 presentation evidence。presentation evidence 仍是本地合成评审材料，
  不拥有业务 authority。
- **Connected same-Case continuation：** PR #103 将已有同一 Case 的
  DecisionReceipt 与 TimelinePlan 继续接入现有 plan execution、checkpoint、receipt、
  recovery、role-handoff、blocked 与 reassessment 路径。它保持 local synthetic、
  provider-free；independent seeded Happy and Blocked scenarios 仍然独立。
  The connected same-Case continuation changes no product authority。
- **Maintenance and hosted proof：** PR #78 的已合并 frontend dependency
  maintenance、Next.js `16.3.3` security patch、CodeQL default setup 与现有
  hosted-proof reconciliation 纳入 release surface。本版本明确为 not audit-zero，
  不把 point-in-time 状态写成永久安全结论。

## Verification

Candidate 必须先通过 release/documentation contracts 的 RED → GREEN，再通过
provider-free Python、frontend、Compose/database、real-Chromium browser 与 release
verifier gates。Hosted proof 包括 exact reviewed HEAD 的 CI 与 CodeQL；发布后还要执行
clean-main Gate C、Git-free Gate D 和 official archive Gate E。

## Scope

本 release 只收口 Night Voyager-owned version identities、release notes、verification
guide、current status/docs/contracts 与 release verifier。除声明的 version identities
外，release-prep does not change migration、runtime behavior、backend/domain product
logic、BFF/API endpoints、schemas、dependency choices、Dockerfiles 或 Compose policy。
The release adds no new migration, no mutation authority, no state transition, no automatic retry, and no automatic successor。

## Risk / Impact

这是 local synthetic、provider-free portfolio release，不是 no production deployment
的替代表达：它明确 no production deployment、no real student records、no real
institutional coverage、no advisor-team adoption、no admissions outcome、no
business-benefit claim 与 no HA/SLA。它不宣称 production tenancy、真实用户、服务可用性
或采用结果。
Non-claims: no production deployment; no real student records; no real institutional coverage; no advisor-team adoption; no admissions outcome; no business-benefit claim; no HA/SLA。

DRA 的 strict live acceptance 仍为 `INCOMPLETE_PENDING_LIVE_ACCEPTANCE`。既有尝试
保留 zero cited Evidence 并在 candidate import 前安全停止；no third provider attempt，
且 no third DRA provider attempt。任何后续 live provider、信息增益、跨项目成功或生产
部署都不属于本 release。
